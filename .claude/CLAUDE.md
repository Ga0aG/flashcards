# 项目概述

卡片式语言学习APP-flashcards，遵循艾宾浩斯遗忘曲线辅助记忆

# 功能描述

- 设置界面
  - 设置主语言
  - 设置每次复习的时候的默认单词数量
  - 单词分页数量
- 主页
  - 默认进入单词本界面，可以创建不同的单词本，点击单词本，可以进入单词本界面；单词本不需要创建名字，用户根据国旗来选择语言，暂时支持学习日语，英语，汉语，意大利语，西班牙语。同时顶部增加一个模式选择，目前的选择有单词本，场景本。
  - 单词本界面
    - 由新到旧地显示单词，每个单词会显示对应的译文和发音（日语的发音用字母表示）
    - 单词词条有对应的编辑和删除按钮，如果点击删除的话需要二次确认, 另外还有个喇叭按钮，点击喇叭能发音
    - 词条不需要显示对应的标签，可以用浅色的分割线分开
    - 右上角分别是搜索符号，大脑符号，标签符号，加号
    - 在以上符号的下方有个下拉框，可以过滤标签。要有个“无”也就是不过滤的选项
    - 点击加号进入添加单词界面
    - 点击大脑进入记忆强化界面
    - 搜索按钮可以搜索单词
    - 点击标签的管理界面
    - 本层级以及后续的层级的左上角都有个后退的按钮，可以回到上一层级
    - 添加单词界面
      - 输入框分为卡片正面，卡片背面，单词发音，卡片注释，标签列表。
      - 用户在卡片正面输入单词，在卡片正面的输入框上方有个生成的按钮，点击后程序会自动在网上查询单词翻译成“主语言”的译文填入卡片背面，自动在网上搜索对应单词的常用例句（包括例句的翻译）在卡片注释，自动在网上获取发音。2s超时。这三个框用户都可以自行修改。
      - 单词发音也是自动在网上搜索填充，用户可以修改
      - 支持给单词设置多个标签，标签通过下拉框选择（支持搜索），选中的标签会出现在标签的输入框里，被一个小圈圈着，圈的右上角有个小x号，可以删除。单个单词不能有重复的标签。
      - 注释框下有个确认按钮，用户点击确认后把单词添加进单词本
    - 记忆强化界面
      - 显示当前标签列表，最顶上是所有标签。如果用户选择全部标签，那就在单词本里的所有单词里选择单词复习；如果用户选择了某个标签，就在某个标签里选择单词
      - 选完标签页之后弹出要复习的单词的数量，默认20个，这个也可以在设置里面调整；以及选择是否要用反推模式，显示译文，不自动发声，用户需要回想读音
      - 根据艾宾浩斯遗忘曲线选词，优先选择"到期"需要复习的单词，旧单词（created_at 早的）优先出现。当天已通过的单词当天不再出现。
      - 选择N个单词进入复习队列
      - 单词以卡片的形式出现，可以选择显示单词/语音的模式
      - 第一次点击单词，显示单词的注释，第二次点击单词显示单词的译文，第三次点击的时候回到单词，以此循环。
      - 卡片下方有个喇叭，用户点击它就会发声
      - 左划单词卡片的时候，单词卡片要跟着动，显示“记住啦”。如果用户左划后松开，这个单词的记忆程度进入下一个等级（如果上次答对时间是同一天的话，不会进入下一个等级），从队列里删除，更新“上次答题正确时间”。如果用户右划，显示“再来一次”。右划的单词记忆程度都会回到1，并回队列的尾部。
      - 并且如果在本次记忆训练阶段单词被右划了，它不会在本次训练中进入下一个等级，记忆程度只会是1
    - 标签管理界面
      - 右上角有个加号，用户可以添加标签
      - 列出所有单词的标签集合（数据库最好有个标签表）
      - 每个标签词条旁边有个数字，笔（编辑符号），垃圾桶（删除符号）
      - 数字N代表有N个单词带上了对应的标签
      - 点击删除标签的话，所有带上这个标签的单词都会删除它对应的标签，比如单词A原先有标签A1和A2, A1被删除了，那单词A就只剩下标签A2了
      - 点击编辑按钮的话，是对标签重命名，所有带上这个标签的单词对应的标签也要做修改。比如单词A原先有标签A1，A1被重命名成A2了，那单词A的标签就变为了A2
  - 记忆程度
    - 等级序列：1, 2, 4, 7, 15, 30，对应艾宾浩斯复习间隔天数
    - 单词词条还会标注记忆程度，目前有六个程度，可以是个五叶草，程度1叶子就都是灰的，程度加深一级就亮一片叶子，有更适配的符号也可以换
  - 程序内部逻辑
    - 要存储单词本，每个单词本下有单词，单词需要存储创建时间，标签，译文，注释，发音，记忆程度，上次答题正确时间。
    - 选词算法（艾宾浩斯分层选词）：
      - 到期判断：memoryLevel=1 或从未答对（lastCorrectAt=0）始终到期；其他等级距上次答对超过 memoryLevel 天则到期
      - 第一步：排除当天已通过的单词（lastCorrectAt 是今天）
      - 第二步：到期单词按 createdAt 升序排列（旧词优先）
      - 第三步：到期单词不足 N 个时，从未到期单词中按"距到期最近"补充
  - 场景本界面
    - 场景学习下就是可以新增场景，比如公共交通，餐厅，学校，早晨，公司。
    - 场景右边有个笔的编辑符号（可以编辑场景的名字），和垃圾桶的删除符号，
    - 右上角可以选择语言，比如日语。
    - 点击进入某个场景之后
      - 一个类似于聊天的界面，像两个人在对话，大概像是这样
        | "你好"              |
        |               "你好"|
        |"要一起去吃个饭吗"     |
        |            "我的荣幸"|
      - 页面下方左右各有一个加号，点击左边的加号，可以输入并增加左边的人的一句话，点击右边的加号，可以增加右边的人的一句话。但是我输入的是主语言中文，需要根据右上角用户选择的目标语言翻译成目标语言，翻译后用户可以编辑，在聊天框里显示双语。
      - 当我点击/右键某一句话。我可以编辑这句话，或者删除这句话，也可以选择在这句话的上方或者下方增加一句左或者右边人的话
      - 我希望这个句子要存在数据库里，这个域可以是，场景名，句子在场景里的顺序，主语言，译文，（这个译文后续根据语言的增加，所以这个列也可能会增加）
      - 比如说我现在目标语言是日语，当我要切换到法语时，点击了某个场景，那需要自动地请求api把例句都翻译成法语，更新数据库的列名和翻译的内容。
